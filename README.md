# 취향잔 (가칭): F&B 취향 매칭 웹 프로토타입

카페나 바 사장님이 매장 사진과 함께 추구하는 맛·향·분위기를 등록하면, 일반 사용자가 자신의 취향과 맞는 매장을 틴더처럼 카드를 넘기며 찾습니다. 매칭이 되면 채팅방이 열리고 연락처를 주고받을 수 있습니다.
정부지원사업 사업계획서 증빙에 쓰기 위한 **프론트엔드 전용 작동형 프로토타입**입니다. 서버와 DB 없이 더미 데이터로 동작하며, 입력한 상태는 브라우저 localStorage에만 저장됩니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 정적 파일 생성 (Vercel·Netlify·GitHub Pages 업로드 가능)
```

`dist/` 폴더는 상대 경로(`base: './'`)와 HashRouter를 쓰기 때문에 어떤 정적 호스팅에 올려도 새로고침이나 딥링크가 깨지지 않습니다.
- **Netlify**: https://app.netlify.com/drop 에 `dist` 폴더를 끌어다 놓으면 바로 배포 링크가 생깁니다.
- **Vercel**: `npx vercel --prod`

### Claude Artifact로 배포

```bash
npm run build:artifact   # dist-artifact/ 에 artifact.html + assets + img 생성
```

이 모드에서는 라우팅을 메모리에서 처리합니다(Artifact 뷰어가 `#/경로` 형식의 해시를 넘겨주지 않기 때문). 이미지는 `public/img`에 넣어 함께 배포하고, 외부 리소스는 Google Fonts만 불러옵니다. 사진을 바꿨다면 `node scripts/fetch-images.mjs`로 `public/img`를 다시 받으세요.

## 화면 구성 (7개 핵심 화면)

| # | 화면 | 주요 인터랙션 |
|---|------|---------------|
| ① | 시작 · 역할 선택 | 사장님 또는 사용자 모드 진입 |
| ② | 사장님 · 매장 등록 | 사진 업로드(최대 5장, 미리보기·삭제), 매장명·업종·주소·영업시간·시그니처·소개·연락처 입력 |
| ③ | 사장님 · 취향·특성 설정 | 메뉴 종류 칩, 맛 5축(단맛·산미·쓴맛·바디감·도수) **범위 슬라이더**, 향 키워드, 매장 이미지 키워드 → 등록 후 내 매장 카드 미리보기 |
| ④ | 사용자 · 프로필·취향 | 3단계 진행바 (기본 정보 → 메뉴·맛 범위 → 향·분위기) |
| ⑤ | 카드 스와이핑 | 좌우로 끌기, ✕/★/♥ 버튼, 사진 좌우 탭, ⓘ 상세 바텀시트, 취향 일치율과 겹치는 키워드 강조 |
| ⑥ | 매칭 성사 · 매칭 목록 | 매칭 축하 모달, 새 매칭과 대화 목록, 응답 대기 매장 |
| ⑦ | 채팅 · 연락처 교환 | 사장님 자동 인사·자동 응답, 빠른 답장 칩, 📇 연락처 카드 교환 |

데스크톱에서는 휴대폰 목업과 함께 왼쪽에 **화면 흐름 바로가기**가 나와 발표 시연에 쓰기 좋습니다. 모바일에서는 전체 화면으로 표시됩니다.

## 시연 시나리오 (약 1분)

1. 시작 → **사장님으로 시작하기** → 오른쪽 위 *예시 채우기* → 다음 → *예시 채우기* → 등록 완료
2. **손님 화면에서 내 카드 확인하기** → *예시 채우기* → 다음 × 2 → 취향 매칭 시작하기
3. 맨 위에 방금 등록한 매장 카드가 나옵니다. 카드를 좌우로 끌거나 버튼을 눌러 넘깁니다.
4. 일치율이 60% 이상인 매장에 ♥를 누르면 **매칭 성사** → 사장님과 대화 시작하기
5. 빠른 답장 칩(예약, 추천 메뉴 등)을 누르거나 직접 입력 → 사장님 자동 응답 → **📇 연락처 교환**

> 매칭 규칙(더미): 사용자와 매장의 향·분위기·메뉴 키워드가 얼마나 겹치는지, 맛 범위가 얼마나 겹치는지로 일치율을 계산합니다. ♥ 시 일치율이 60% 이상이면 바로 매칭되고, 그보다 낮으면 "사장님 응답 대기"로 분류됩니다. ★(꼭 가볼래요)는 항상 매칭됩니다.
> 데이터를 처음 상태로 돌리려면 시작 화면 하단이나 프로필 탭의 *데모 초기화*를 누르세요.

## 시안 이미지

`screenshots/` 폴더에 화면별 390×844 @2x PNG 14장과 데스크톱 발표용 1장이 들어 있습니다. 다시 만들려면 dev 서버를 켠 상태에서 아래 명령을 실행하세요. 로컬에 설치된 Chrome 또는 Edge를 사용합니다.

```bash
npm run screenshots
```

## 기술 스택과 구조

React 18 + TypeScript + Vite, Tailwind CSS v4, framer-motion(스와이프·애니메이션), react-router(HashRouter)

```
src/
  data/keywords.ts     맛·향·분위기 키워드, 맛 5축 정의
  data/stores.ts       더미 매장 9곳, 자동 응답 문구
  lib/match.ts         취향 일치율 계산
  state/AppContext.tsx 프로필·매장·스와이프·매칭·채팅 상태 (localStorage 저장)
  components/          SwipeCard, MatchModal, RangeSlider, KeywordChips, PhotoUploader, PhoneFrame
  screens/             화면별 컴포넌트
```

매장 사진은 Unsplash 무료 이미지를 URL로 불러옵니다. 오프라인이거나 이미지를 불러오지 못하면 그라데이션 배경으로 대신 표시됩니다. 등록 화면에서 직접 올린 사진은 축소한 뒤 브라우저에 저장됩니다.
